# NewBee Agency — Landing Page

Landing page promosi untuk **NewBee Agency**, digital agency yang membantu UMKM bertumbuh melalui strategi digital, advertising, creative content, website, dan brand strategy.

## Menjalankan secara lokal

Project ini menggunakan HTML, CSS, dan JavaScript vanilla sehingga tidak membutuhkan proses build atau dependency tambahan.

```bash
# Clone repository
git clone https://github.com/ariantoekaputra99/umkm-digital-agency-landing-page.git
cd umkm-digital-agency-landing-page

# Buka index.html di browser
```

## Struktur

- `index.html` — struktur dan konten halaman
- `styles.css` — desain responsif modern minimalis
- `script.js` — mobile menu dan animasi reveal
